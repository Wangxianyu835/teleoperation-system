## 三遍阅读法

### 第一遍：15–20 分钟判断相关性

顺序：标题与摘要 → 方法总图 → 引言末尾的贡献 → 主要实验表格与图 → 结论及局限。

先不逐句翻译，也不逐个推导公式。完成以下五句话即可：

1. 这篇论文解决的具体失败是什么？
2. 输入是什么，运行时额外需要什么信息？
3. 输出是什么，是否包含腕部、手臂或动态控制？
4. 最关键的改变是什么？
5. 它用什么证据证明改善，与我的项目有什么关系？

给论文分类：精读 / 作为背景 / 暂存。时间是参考预算，不是必须读完的期限。

### 第二遍：60–90 分钟理解机制与证据

围绕四条线阅读：问题定义、方法、实验、局限。每个关键公式都写清变量、坐标系、单位、归一化、权重和计算时机。

对重定向目标特别检查：

- 哪些量在人手上测得，哪些量由机器人 FK 计算？
- 目标是否超出目标手的可达能力？耦合关节如何处理？
- 是绝对位置、相对向量、方向、距离，还是接触关系？
- 自碰撞和手物穿透采用什么几何近似？
- 约束是软惩罚还是求解时必须满足的条件？
- 时间窗口能否在线使用？是否使用未来帧？
- 报告的速度是否包含感知、通信、优化和执行？

实验中至少找出：最强基线、一个消融、一个失败案例，以及限制结论范围的实验条件。

### 第三遍：2–4 小时起步，围绕一个部件动手

只对最相关论文开展。先读官方代码的输入处理、核心目标、FK/求解器、输出转换和评估，再做一个最小实验。

最小实验例子：固定一段捏合输入，在同一手型、同一输入、同一执行策略下比较原目标与新增目标，输出捏合误差、限位饱和情况和耗时。先不同时更换网络、损失和滤波。

第三遍可以产出伪代码或未解决问题；完整复现往往需要更多时间。区分“论文报告”“代码确认”“我已复现”“我的推测”。

## 结合本项目的阅读练习

从 GeoRT 开始，画一张输入到输出的图，分别标明人体关键点、映射网络、机器人运动学以及训练损失。然后做以下对照：

| 对照点 | 本项目入口 | 阅读任务 |
|---|---|---|
| 当前六项几何损失 | `src/teleoperation/learning/losses.py` | 对照 GeoRT 的目标，记录相同点、不同点与缺失的评估维度 |
| 模型输入输出 | `src/teleoperation/retargeting/hand/predictor.py` | 确认三帧、25 点输入和目标手原生关节输出的含义 |
| 可微 FK 与目标 | `src/teleoperation/retargeting/hand/hand_model.py` | 区分人体归一化空间与机器人米制空间 |
| 优化后端 | `src/teleoperation/retargeting/hand/dex_native.py` | 确认当前 VectorOptimizer 的目标，不把它自动当作 DexPilot 实现 |
| 评估 | `src/teleoperation/learning/hand_evaluation.py` | 分别检查原始预测、执行命令、几何误差、时延与缺帧 |
| 数据划分 | `src/teleoperation/learning/trainer.py` | 区分同录制时间分段验证和跨操作者、跨场次测试 |

首个研究假设可写成：在低自由度与耦合手型上，按抓取意图和可达能力分配目标优先级，比固定权重几何目标改善捏合或抓取表现。

这是待验证的假设，不是已经证明的新颖贡献。GeoRT 已研究空间覆盖，DexMachina 已研究功能重定向，DexOAK 已研究物体感知与接触保持；后续需精确定位方法差异。

## 阅读产出与进度

每篇精读论文保留一页主笔记，公式推导和复现日志另附。复制同目录的 `paper-note-template.md`，文件名可以使用 `geort-note.md` 等。

建议第一周完成：

1. 第一次：GeoRT 第一遍阅读，完成五句话与一张流程图。
2. 第二次：GeoRT 第二遍阅读，补齐目标函数与实验条件。
3. 第三次：Key Objectives 第一、二遍阅读，比较目标与消融。
4. 第四次：DexPilot 和 AnyTeleop 浏览阅读，补齐优化与系统背景。
5. 第五次：DexOAK、DexMachina 第一遍阅读，检查选题是否重复。
6. 第六次起：选择一个目标或一个失败类型，设计最小对照实验。

进度以能否解释方法、指出证据并设计实验衡量。遇到陌生术语先列清单；只有挡住核心理解时才深入补课。

使用 AI 时给出对应段落、公式或表格，并要求定位原文、解释假设、区分事实与推测。数值、比较结论与创新性判断都回到原文核对。
