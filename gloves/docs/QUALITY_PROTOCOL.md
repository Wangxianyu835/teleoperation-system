# FFG 简化质量验证

## 目的

验证 FFG 能够连续采集、正确响应手部动作，并生成可交付数据。

## 建议动作

录制时完成以下动作即可：

1. 手掌自然张开，静止约 5 秒；
2. 张开—握拳循环 10 次；
3. 拇指与食指做 O 型捏取 10 次；
4. 五根手指各独立弯曲 3～5 次；
5. 需要稳定性测试时，连续采集 5 分钟。

## 自动检查

`04_review_data.py` 只报告六个指标：

- 实测帧率；
- 无效帧比例；
- 最大帧间隔；
- 动作范围；
- 静止抖动；
- 端点饱和比例。

详细指标保存在 JSON 中，不全部打印到终端。

动作范围和静止抖动只使用五指屈曲通道。侧摆通道噪声单独保存在 JSON
的 `neutral_side_std_rad` 中，不会污染手指主屈曲效果的可视化。

## 结论含义

```text
PASS：采集链路正常，可以继续重定向工作
WARN：数据可用，但应检查动作、串口或质量门槛
FAIL：数据缺失或不完整，不能交付
```

当前质量门槛用于采集链路健康检查。最终是否能驱动特定机器人，仍需由重定向负责人验收。
